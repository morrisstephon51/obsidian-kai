# Recurring Behaviors

**Building agents to manage agents/work.** First the content automation pipeline, then the Architect Agent (multi-agent orchestration), then the Grant Research Agent, then JobScout. Each new domain of work tends to get its own AI agent built for it relatively early, before the underlying process has necessarily been validated manually.

**Pitching internal value to employers.** The BigHeart pitch (content automation tool → title change → comp adjustment) follows a pattern: build something valuable inside an existing structure first, demonstrate it, then formalize recognition after the fact. This worked well enough to be repeated as a strategy.

**Cross-pollinating projects.** Assets built for one context get reused in another — BigHeart's "My Health My Power" work doubles as a Plug AI case study; the five-document framework built for one project gets applied to the other; brand voice guidelines apply across both LinkedIn content and grant materials.

**Returning to "the gap" framing.** Across brand work, scholarship essays, and self-description, the same core narrative elements recur: "the gap," "people like me," "people the tech world forgot," "the plug is in." This consistency is a strength for brand coherence but also suggests this narrative may be somewhat fixed/unexamined — worth occasionally stress-testing whether it's still the most accurate or compelling framing as the work matures.
