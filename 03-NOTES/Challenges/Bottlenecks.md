# Bottlenecks

This is the most important note in the vault. If you fix one thing, fix this.

**The real bottleneck is not skill, resources, or even funding access — it's sequencing.** Stefan has, simultaneously: a grant pipeline (Kresge LOI, DCEO, Woods Fund prep), a content automation system needing ongoing maintenance, two AI agents in development (Architect Agent, Grant Research Agent), a job-search automation tool (JobScout), a BigHeart internal pitch for title/comp, an active CS degree plus four certifications, and a recently submitted scholarship essay. Each of these individually is reasonable. All of them at once, solo, with zero budget, is not a strategy — it's a list of things that are all "in progress" and therefore none of them are getting finished fast.

**Specific bottleneck #1: The BigHeart pitch is sitting in the same priority tier as everything else, when it should be #1.** It requires no new external relationship, no new funding approval from a stranger, and addresses the zero-budget constraint most directly and fastest. If this hasn't been formally raised with BigHeart leadership yet, that conversation is the highest-leverage single action available.

**Specific bottleneck #2: The five-document framework and LLM Council, applied universally, are a tax on velocity.** For The Plug AI's current stage (pre-revenue, proof-of-concept, grant-pipeline), the highest-value activities are: (a) finishing the Kresge proposal, (b) the BigHeart conversation, (c) maybe one more church/community pilot to strengthen the case studies. None of these need a five-document pre-development process or a four-persona council. Reserve that machinery for actual software builds with real complexity (the content automation pipeline, agent architecture) — not for strategic/relational moves.

**Specific bottleneck #3: No visible feedback loop on which workstream is actually working**, except for the one case (LinkedIn content) where data was looked at and acted on. Apply that same discipline elsewhere: is the Grant Research Agent actually producing better grant matches than manual research would? Is JobScout producing interviews? If not, that's information to act on, not just iterate on.
