# Obsidian Vault Instructions

## Vault Purpose
This vault is my second brain. It stores my projects, ideas, research, decisions, writing, and daily notes.

The goal is not storage. The goal is connection, synthesis, and better output.

## Vault Structure
- **00-INBOX** — raw captures
- **01-DAILY** — daily notes
- **02-PROJECTS** — active projects
- **03-NOTES** — permanent notes
- **04-RESOURCES** — source material
- **05-MAPS** — topic maps
- **06-OUTPUTS** — finished work
- **07-AI** — AI-generated briefs, audits, summaries, and connection reports
- **08-ARCHIVE** — inactive material
- **09-SYSTEM** — templates, prompts, and instructions

## Note Rules
- Keep notes in Markdown.
- Use clear titles.
- Use properties at the top (frontmatter).
- Link related notes with [[wikilinks]].
- Permanent notes contain one main idea.
- Every permanent note connects to at least two other notes.
- Use the templates in `09-SYSTEM/templates/` when creating new notes.

## AI Rules
Before answering from the vault:
1. Search relevant notes first.
2. Prefer my own notes over general internet answers.
3. If the vault does not answer something, say what is missing.
4. When creating a new note, follow existing folder and naming rules.
5. Save useful AI outputs into `07-AI/`.
