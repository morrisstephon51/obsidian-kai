## 🚀 How to Use Your New System

### **Daily Workflow**
1. **Morning:** Open `_ops/master-tracker.md` → See today's priorities
2. **Work:** Execute projects linked to goals
3. **Evening:** Create daily note (use `09-SYSTEM/templates/daily-note.md`)
   - Link what you worked on to projects
   - Link results to goals
   - Capture decisions and learning

### **Weekly Workflow**
1. **Saturday:** Create weekly review (use `09-SYSTEM/templates/weekly-review.md`)
2. **Review:** Aggregate daily insights, identify patterns
3. **Update:** `01-DAILY/Progress Dashboard.md` with status
4. **Reflect:** Bubble insights back to goals and vision

### **Opportunity Evaluation**
1. **See:** `Opportunities/index.md` for active opportunities
2. **Evaluate:** Against Core Values, Career Goals, Finance Goals
3. **Decide:** Create decision journal entry
4. **Record:** Link back to opportunities hub and goals

### **Navigation Patterns**

**Top-Down (Planning):**
- Start: `02-PROJECTS/Personal Growth/Core Values.md` or `Life Vision.md`
- Flow: Values → Goals → Projects → Daily Actions

**Bottom-Up (Synthesis):**
- Start: `_ops/master-tracker.md`
- Flow: Daily Work → Weekly Reviews → Progress Dashboard → Vision Refinement

**Network (Discovery):**
- Pick any note
- Follow links
- Discover unexpected connections
