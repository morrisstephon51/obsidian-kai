# HTML Structure Practice
*Notes from February 11, 2025*

Practice exercise building an HTML page with semantic structure and proper meta tags.

## Key Elements Used
- `<!doctype html>` declaration
- `<meta charset="utf-8">` — character encoding
- `<meta name="viewport" content="width=device-width, initial-scale=1">` — responsive scaling
- `<header>`, `<main>`, `<footer>` semantic layout tags
- `<h1>`, `<h2>`, `<h3>` heading hierarchy
- `<img>` with `src`, `alt`, `width`, `height` attributes
- `<ul>` / `<li>` unordered lists
- External CSS linked via `<link href="css/style.css" rel="stylesheet">`
