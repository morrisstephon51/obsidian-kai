## 🚨 Troubleshooting

**If any link is down:**

1. **Check GitHub Actions** — Deployment may have failed
   - Go to: https://github.com/morrisstephon51/Link-inbio
   - Click "Actions" tab
   - Check recent deployments

2. **Test Locally** — Build and test locally first
   ```bash
   npm run build
   npm run dev
   ```

3. **Check GitHub Pages** — Verify GitHub Pages is enabled
   - Settings → Pages
   - Verify branch is main and /root is selected

4. **Clear Cache** — Browser cache may show old version
   - Hard refresh: Cmd+Shift+R (Mac) / Ctrl+Shift+R (Windows)
