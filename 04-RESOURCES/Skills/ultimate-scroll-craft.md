# Ultimate: Scroll-Craft Skill

**Premium, scroll-driven website builder for brandable landing pages.**

## What It Does

Builds **interaction-first, craft-standard** scroll experiences:
- **Scroll as timeline:** Video frame-scrubbing, pinned sections with advancing argument, lateral rails, typographic reveals, color shifts, pointer-driven elements
- **8 page grammars:** Filmic one-shot, chaptered editorial, live surface, continuous world, typographic poster, gallery, split stage, rhythmic cutlist (no shared skeleton between builds)
- **Bespoke signature move:** Every page invents one unique interaction that exists only on that site
- **Fingerprint gate:** Each new build must differ from prior work on ≥4/6 dimensions (grammar, nav, hero, act shape, close, signature move)

## Craft Standards

- **Feeling curve:** One line per act (emotion + what causes it on screen)
- **One engineered peak:** Peak-end rule applied — peak gets asset budget + silence + scroll room
- **Typography floor:** 2 families max, tracked tightening with size, 45–75ch measure, adaptive line-height
- **Spacing rhythm:** 4px base, more space above headings, fluid section padding
- **Color with rules:** 6 roles + 1 accent, tinted secondary text (no flat grey), compensated light-on-dark
- **Depth toolkit:** Offset shadows, edge light, scale-blur distance, overlap, grain
- **Brand integration:** Hard rules from brand kits override skill defaults
- **Refuse list:** No feature grids, counters, scroll cues, gradient text, invented stats, AI-purple, artisan cream-and-brass

## Quality Checks

Automated headless browser inspection:
- Dead scroll detection (scroll with no visual change)
- Faded copy discovery (cues never reaching full opacity)
- Contrast measurement per line at brightest frame (light-on-dark + dark-on-light)
- Decode verification (clips that never parsed)
- Contact sheet generation for manual review
